# Ivory County website replica

A self-contained static replica of the Ivory County marketing page.

## Preview

Serve the `dist` directory with any static server. For example:

```powershell
npx serve dist
```

The replica keeps the reference site's responsive layout, hero video, amenities, location tabs, project cards, RERA section, inquiry modal, mobile navigation, and footer. Third-party analytics and chat trackers are blocked, and the inquiry form uses a local confirmation instead of transmitting visitor data.
